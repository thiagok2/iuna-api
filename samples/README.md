# Samples

Pasta com PDFs de exemplo para testar a extração de texto e a ingestão na API.

## Arquivos

- `generate_sample_pdfs.py` — Gera PDFs de exemplo para testes
- `test_extractor.py` — Testa o extrator de PDF com os arquivos gerados

## Uso

```bash
# Gerar PDFs de exemplo
python samples/generate_sample_pdfs.py

# Testar extração
python samples/test_extractor.py
```
